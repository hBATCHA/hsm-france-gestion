# H.S.M.FRANCE Gestion

Application web interne de facturation, bons de livraison, gestion des clients, paiements et suivi de stock pour H.S.M.FRANCE.

## Objectif du MVP

Le parcours principal est volontairement simple :

1. sélectionner ou créer un client ;
2. préparer et valider un bon de livraison ;
3. diminuer le stock une seule fois ;
4. transformer le bon en facture ;
5. imprimer ou envoyer le document ;
6. enregistrer les paiements et suivre les impayés.
